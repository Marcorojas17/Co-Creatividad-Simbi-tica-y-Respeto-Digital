# Política de Calidad ISO 9001

**KRONOS-28-ITZA** se compromete a:
- Entregar software funcional, documentado y testeado.
- Mantener un ciclo de mejora continua.
- Asegurar la satisfacción de los usuarios mediante soporte y actualizaciones.

## Indicadores
- Cobertura de pruebas > 80%.
- Tiempo de respuesta < 200ms.
- Disponibilidad > 99.9% (SLA).
