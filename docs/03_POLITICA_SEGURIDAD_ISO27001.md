# Política de Seguridad ISO 27001

## Alcance
Protección de datos, integridad de código y trazabilidad de eventos.

## Controles
- Firma GPG en todos los artefactos críticos.
- Hash encadenado (NOM-151 L2).
- Separación de secretos (`.env`, `secrets/`).
- Auditoría continua con `audit.py`.
