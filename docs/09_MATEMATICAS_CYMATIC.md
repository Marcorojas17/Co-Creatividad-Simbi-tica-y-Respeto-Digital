# Matemáticas Cimáticas

## Frecuencia Base
- Base: 440 Hz
- Fórmula: `f(n) = 440 * 2^(n/12)`
- Rango: 28 Hz – 28 kHz

## Geometría Chladni
- Placa: cuadrada / circular
- Modo: `m:n`
- Ecuación: `A(x,y) = sin(π·m·x) · sin(π·n·y)`

## Motor
- WebGL + GLSL (gold shader)
- Entrada: audio / mic / oscilador
- Salida: patrón cimático + hash sellado
