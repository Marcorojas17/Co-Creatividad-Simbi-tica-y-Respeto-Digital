## 📜 Código de Conducta

## 🐛 Reporte de Issues
- **Bugs:** Usa la plantilla de bug report. Incluye pasos para reproducir, versión, logs y si has corrido `compliance:seal`.
- **Features:** Describe el problema que resuelve, el contexto y el valor para el proyecto.
- **Security:** Reporta vulnerabilidades a `security@kronos-28-itza.dev` (nunca en issues públicos).
